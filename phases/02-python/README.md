# Phase 2: Python

Learn Python fundamentals, then use them to work with data and solve analytics oriented problems.

## Learning objectives

By the end of this phase, you should be able to:

- Write basic Python expressions and use common data types.
- Organize code with functions and collections.
- Explain basic object-oriented programming concepts
- Work with generators, decorators, and exceptions
- Read and write files.
