# Phase 1: Statistics Foundation

Build the statistical foundation needed to analyze data , evaluate models and reason about financial markets.

## Learning objectives

By the end of this phase, you should be able to : 

- Summarize data using descriptive statistics.
- Calculate and reason about basic probabilities
- Recognize common probability distributions.
- Explain the basics of hypothesis testing.
- Distinguish correlation from covariance.
- Describe what regression models.
- Identify common patterns in time series data.
